# Spectre AutoBuild and Light Debug

The supplied Spectre Client 26.2 source credits **4ldenz**, with the license **GPL-3.0-only**. Its builder data model, `SchematicReader`, material resolver, material/shulker plans, saved build jobs, `CreativeBuilder` and `GroundNavigator` are ported under `dev.donut.client.spectrebuilder`. Native adapters connect them to Donut's existing schematic manager, model preview, world ghosts, input, inventory and HUD. The original Donut executor remains available. The source framework and ImGui dependency are not required.

AutoBuilder defaults to **Spectre Creative**. This source executor requires Creative mode and an integrated single-player server. It uses ordinary grounded walking, smooth aiming, real placement/bucket interactions, inventory selection and integrated-server confirmation. It sorts structural blocks before redstone and fluids, supports source fluids and waterlogged placement, configures repeater delay and verifies the exact resulting states. It never directly sets world blocks. It requires all item types in inventory; **Get Materials** remains an explicit Creative-only action provided by Donut. It does not order or purchase materials.

The source limitations remain: no automatic placement of beds, doors, double-height plants, piston heads or moving pistons; no flight, teleporting, mining, automatic scaffolding or resupply. Existing occupied cells must already match. A reachable visible ground approach is required; final connected/powered states must arise from the actual build. The source executor rejects unsupported states or reports failure instead of substituting blocks. **Survival / multiplayer** selects Donut's existing executor and its existing placement/support behavior.

The library adds Sponge `.schem` v2/v3 via the bounded source reader, alongside Donut's existing `.litematic` v4–7 support. Positions and states share Donut's rotation/mirroring transform. Sponge offsets normalize to the minimum corner; preview before starting. Source `.schem` limits are 64 MiB compressed/expanded and one million region cells. Auxiliary NBT is parsed by the source model, but construction does not restore entities, container contents or scheduled ticks.

**Place in world** adapts the source's interactive placement controls: aim at terrain, **R** rotates, **Page Up/Down** changes height, and **Enter** anchors. It sends no placement packets and blocks mining/use while positioning. **Show in world** retains Donut's existing fixed-position preview. Ghost rendering uses Donut's bounded native geometry rather than Spectre's newer Gizmos API.

**Materials → Shulker packing** exposes the source's full-schematic quantities, stack counts, 27-slot box allocations and items that must travel separately. The text preview shows up to 500 allocations; saved plans retain all quantities. Waterlogged cells additionally need a reusable water bucket. Live inventory/remaining counts stay in the existing materials table. **Save plan** writes an atomic UUID-named JSON file under `config/donut/builder/jobs/`. **Plans** in the library lists individual saved jobs; **Restore** reads the newest plan. Both verify the same server/world/dimension and the schematic SHA-256, and restore position, rotation and Donut's mirror extension. Neither starts movement or construction. Changed files require reloading before a new plan can be saved.

Light Debug ports **only `LightEspModule`**, `LightSnapshot` and `SessionWorker`, as requested. Player Bypass and Prime Chunk Finder are excluded. Controls retain the source defaults/ranges: radius 8 chunks (1–16), minimum light 5 (1–15), denoise on and translucent red, with editable color/alpha. It scans only already-loaded underground sections below Y 0 and retains block light brighter than skylight. Collection is limited to 16 chunks / a two-millisecond deadline between chunks per tick, with a 250,000-cell cap and a one-second scan cooldown. A cancellable worker receives detached data, removes weak isolated light fields when denoise is enabled, and produces up to 12,000 exposed-cell boxes.

The native renderer draws these boxes through walls, preserving the source's light-dependent white grading, fill alpha and dark outlines. Changed scan settings, disabling, world changes and disconnects discard pending work and geometry. Light Debug is appended at module index 11; existing keybindings retain their indices. It supports Visual search, favorites, a native Controls shortcut and the array list. Its light filter depends on data sent by the server; this module has no additional source bypass modes.

The combined distribution includes GPL components and matching source. Original Donut MIT authorship and separate font/Name Hider notices remain preserved. See the bundled `licenses/spectre-builder-light-port.txt` and `licenses/spectre-GPL-3.0.txt`.
