**Complete static block and material-sound inventory for the Sound Detector plan**

Generated November 6, 2026 from the official-Mojang-mapped Minecraft Java 1.21.11 classes cached by this project. This inventory includes all 1,142 public static final Block constants declared by Blocks and all 123 public static final SoundType constants. Every symbol appears once in its respective inventory.

This is an exhaustive static review checklist, not a completed sound-routing audit. Review-family assignments below are provisional name-based navigation aids. They do not assert that a block emits a sound, that a sound is delivered to other players, or that an action identifies a human actor. A block can require review in several families. Runtime registry IDs, distinct state behavior, special actions, packet routes, silence, shared sounds, and non-player causes must be verified during implementation.

For each block, the implementation coverage report must expand break, step, place, hit, fall, special use, autonomous change, and ambient behavior into explicit statuses: verified packet, verified event-derived, client-derived only, silent/no public signal, ambiguous shared sound, or unverified. Generic sound coverage alone does not complete the special-action audit.
